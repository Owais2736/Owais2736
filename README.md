## 👨‍💻 About Me

I'm a **Frontend Engineer (Web & Mobile)** at **FameWheels**, focused on building scalable, production-ready applications for real-world users.

My primary focus is **React Native mobile development**, while also working extensively with **React.js, Next.js, TypeScript, and the MERN stack** for web applications.

I have hands-on experience across the complete frontend development lifecycle — from UI development and API integration to Firebase services, state management, performance optimization, production builds, and **Android & iOS deployments**.

🚀 I've contributed to **16+ live web and mobile applications**, including automotive marketplaces, e-commerce platforms, HRM systems, CRM dashboards, and real-time vehicle bidding applications.
